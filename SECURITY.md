# Security Policy

## Supported versions

This repository is legacy coursework retained for historical study. No version is currently supported for production use or security updates. Its dependency graph contains known vulnerabilities.

Do not deploy this application or reuse its credentials and configuration without a full dependency upgrade and security review.

## Reporting a vulnerability

Use this repository's **Security > Report a vulnerability** flow so details are shared privately. Do not open a public issue containing credentials, exploit details, or personal data.

Any credential found in Git history must be treated as compromised and revoked at its provider; deleting it from the latest commit is not sufficient.
